# BPM 照合記録（2026-11-08）

追記：資料間の差が大きい、または採用を保留した Same Blue、LADY、Travelers、Editorial、夏模様の猫、ニットの帽子、エルダーフラワーは、サイトではテンポを「調査中」と表示する。以下の数値は照合用の参考値として保持し、確定値・平均値として使わない。

掲載中の90曲を、曲名・掲載音源と現行の出典を確認したうえで、参照可能なコード譜、編曲譜、楽曲データと照合した。表の数値は BPM。採用値は公式設定値の証明ではなく、比較しやすい拍の取り方を選んだ目安。編曲譜は原曲とテンポが異なる場合がある。独立した方法で計測された資料同士とは限らない。

この環境では楽曲音源を直接聴く・タップ計測する検証は行っていない。資料が一致しない曲や別資料を十分に確認できない曲は保留し、数値の単純な半減はしていない。「照合」は資料上の値の比較であり、原音源の BPM を保証するものではない。

- 表中の「資料上おおむね一致」は、参照元が同じデータを共有していないことや、音源を実測したことを意味しない。
- 115万キロのフィルムは今回以前から約97 BPMを掲載しており、約194 BPMの別表記も記録済み。
- 曲ごとの BPM を算術平均するマイセトリの値やテンポ順には、資料による拍の取り方の差が残る。
